# Rebecca's Port and OpenTelemetry Demo

This repository is my customized copy of the OpenTelemetry Astronomy Shop.

## Project goal

Demonstrate how Port connects:

- a GitHub release,
- a deployment,
- degraded checkout performance,
- OpenTelemetry telemetry,
- Grafana Cloud observability,
- and the Revenue at Risk business KPI.

## Repository safety

- `origin` is my personal OTEL-demo repository.
- `upstream` is the official OpenTelemetry repository.
- All project changes are pushed only to `origin`.
